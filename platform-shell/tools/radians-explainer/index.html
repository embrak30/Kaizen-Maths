Why π radians = 180°

Why the conversion works

A radian measures an angle by comparing its intercepted arc length s with the circle’s radius r: θ = s ÷ r. When s = r, the angle is 1 radian, approximately 57.3°.

The wrapping animation preserves the length of the highlighted copy. It first moves that copy to a tangent, then bends it into an arc of the original circle. The small highlighted angle is 1 radian only when the wrap is complete.

A full circumference is 2πr, so a semicircle has arc length πr. Its radian measure is πr ÷ r = π. By the definition of degree measure, the same half-turn is 180°. Thus π radians = 180°. π itself is a number, not an angle unit.

Three one-radian arcs cover only 3 radians. The remaining (π − 3) radians are approximately 0.1416 radians; this remainder is shown separately. The semicircle contains π radius lengths, not exactly three.

Ask: if we double the radius, what happens to the arc length for the same angle? Both double, so s ÷ r is unchanged. Changing the circle’s size never changes the radian measure of a fixed angle.

Explore uses exact π fractions for whole-degree angles and exact 1 radian at its preset. Other displayed numerical values are rounded and marked approximately. This tool covers counterclockwise angles from 0° to 360°.
