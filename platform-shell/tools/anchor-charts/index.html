Elementary Maths Anchor Charts

Purpose

Anchor charts are visual references that capture a key model, rule, vocabulary set, or method. They help pupils return to the idea while practising.

Classroom Flow

  • Choose the chart linked to the concept you are teaching.
  • Start with the visual model before revealing all of the written information.
  • Use Reveal Next to build the chart with the class.
  • Use the write function in Classroom View to add examples, labels, and pupil responses.

Best Use

These are designed for teacher explanation, retrieval, intervention, and display. They should not replace modelling; they give the teacher a clean board-ready structure to build from.
