Teaching with Number Trails

Start at the filled circle. Follow the direction of an arrow and apply the operation beside it. If a circle has two outgoing arrows, both calculations begin with the same number in that circle.

Choose a level, generate a new challenge, or enter a starting number and choose Use start. Every division gives an exact whole-number answer. First steps stays between 0 and 30; Mixed operations stays between 0 and 200; Integer challenge includes negative answers between −500 and 500.

Tap a blank circle to reveal or hide just that answer. Show answers reveals the entire trail; Hide answers restores all the blanks. Teacher guidance stays in this panel.

Print / PDF prints the current diagram, including any answers currently showing. Hide answers first for a question sheet. Use your browser’s Save as PDF option to save a copy.
