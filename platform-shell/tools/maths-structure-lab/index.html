Maths Structure Lab

Purpose

This tool is for teaching the structure behind a method before showing the formal shortcut.

How to Use

  • Choose a structure from the horizontal menu.
  • Use Next Step to reveal the model gradually.
  • Ask pupils to describe what each part represents before revealing the symbolic method.
  • Use New to generate a fresh example within the same structure.

Classroom Questions

  • What is the whole in this model?
  • What has stayed the same, and what has been repartitioned?
  • Where can we see the operation in the diagram?
  • How does the diagram explain the formal rule?
