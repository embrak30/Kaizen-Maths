Teaching the squeeze theorem

If ℓ(x) ≤ f(x) ≤ u(x) throughout a punctured neighbourhood of a, and both bounding functions have the same limit L as x approaches a, then f also has limit L. The value of f(a) need not exist.

Ask for a prediction before each reveal. The distance control probes both sides; animation and zoom illustrate the behaviour. A numerical table or a plotted sample supports observation, but the inequalities and the known bounding limits justify the conclusion.

In the first two examples, |f(x) − L| ≤ (x − a)². Thus for any ε > 0, choosing δ = √ε guarantees |f(x) − L| < ε whenever 0 < |x − a| < δ.

The two “different bounds” examples show why an inconclusive squeeze does not prove that a limit fails to exist: x has limit 0; sin(1/x) has no limit as x approaches 0.

Curves are sampled for display and are not drawn across an undefined point. The bounds give the exact argument.
