A picture before a calculation

Build a collection. Ask pupils to predict what will happen, make a change, then discuss what they see.

  • Add more: add 1, 2 or 5. Count on highlights the new objects; Count all highlights the whole collection.
  • Take away: tap an object or drag it into the taken-away area. Tap a removed object to return it. Move away and Cross out show the same subtraction.
  • Compare: build two groups. Matching columns help pupils see which group has more and how many more.

Hide counts and the number sentence for discussion. Reveal the answer when ready. Undo reverses one change; Reset rebuilds the starting collection. This is a teacher-led display, not a pupil assessment.
