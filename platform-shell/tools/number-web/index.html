Teaching with Number Web

Each branch has three hexagons: one near the centre and two on the outer ring. All three numbers must add to the centre target. Two are given; exactly one is missing. Each branch is independent.

Ask pupils to add the two known numbers, then work out how much more is needed to reach the target. The near-centre number is part of the sum, not a subtotal. Check a completed branch by adding all three numbers.

First steps and Lower primary use four branches and positive whole numbers. Primary uses six branches up to 50. Upper primary uses eight branches up to 200. Decimal challenge uses tenths. Integer challenge includes negative numbers; a missing number can also be negative.
