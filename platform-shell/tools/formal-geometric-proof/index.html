Formal Geometric Proof Guidance

Overview

This tool helps teachers model geometric reasoning as a chain of justified statements. It separates calculation from proof by asking students to name the theorem, identify the matching parts, and write the reason for each conclusion.

Level Guide

  • Level 1: Identify the correct reason from a diagram.
  • Level 2: Build angle-proof chains using parallel lines, triangles, and circle theorems.
  • Level 3: Prove congruence or similarity using corresponding sides and angles.
  • Level 4: Complete formal two-column proofs and paragraph-style proof arguments.

Teaching Focus

  • Insist that every statement has a reason.
  • Ask students to point to the diagram before naming the theorem.
  • Keep corresponding vertices in the same order for congruence and similarity statements.
  • Encourage concise proof language: statement first, reason second.
