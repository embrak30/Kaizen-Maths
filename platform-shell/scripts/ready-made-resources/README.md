# Complete ready-made collections

Run `build-complete.py` with the bundled Python runtime (pypdf required) after rebuilding any of the eight topic libraries. It merges the existing PDFs without rasterising or reflowing pages. All Topic Practice sheets precede all Teacher Pack pages, with section and topic bookmarks. Starter and exit-ticket sources already contain solutions and are retained as complete topic packs.

Outputs: `assets/ready-made-complete/*-complete.pdf`. The manifest records every input hash, page count and offset for verification. The collection includes all topics, tiers and courses on its page, regardless of the current search or filter. The compact download link says this explicitly. Individual Topic Practice and Teacher Pack downloads remain available. This changes website link labels; existing individual PDF content and filenames are preserved.
