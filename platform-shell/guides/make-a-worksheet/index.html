Make your first maths worksheet

Follow the actual Kaizen Maths screens, from choosing a topic to printing the questions, answers and worked steps.

Download the PDF guideOpen Worksheet Builder
1

Open Worksheet Builder

Choose Explore in the sidebar, then select the Worksheet Builder card.

You need an active teacher trial, subscription or school access to use the builder.

2

Choose your topic, level and question type

Give the sheet a title and student instruction. Choose a Topic tool, then a Level and Question type. This example uses Algebraic Substitution.

Levels and question types change to match the selected topic tool.

3

Set the quantity and add the questions

Enter the number of Questions you want, then choose Add selected questions. The selected questions become a block in your worksheet.

Use the quick count buttons for a short practice set. Add the block before choosing another topic.

4

Add another block when you need one

Choose another level, question type or topic, set its quantity, then choose Add selected questions again. Scroll down the controls to check the block list before creating the worksheet. In this example, block 1 has five linear questions and block 2 has three quadratic questions.

For a single-topic sheet, you can keep just the first block.

5

Choose answers and worked steps

Keep Include separate answer key selected if you want the answers. Select Include worked steps to add the solutions. Assessment mode is optional and lets you assign marks.

Worked steps appear with each question. Leave this unticked for independent practice; the separate answer key is for the teacher.

6

Create, check and print the worksheet

Choose Create Worksheet. Check the questions in the preview, then choose Print / Save PDF. In your browser print window, choose a printer or Save as PDF.

Check the page range before printing if you want the pupil questions without the teacher pages.

Screen layout may vary with your window size. The screenshots show a demonstration worksheet and contain no pupil data.

Teacher access only. Kaizen Maths uses adult teacher accounts. Enabled pupil tasks use aliases and store responses and scores; do not enter identifying pupil details. Trust & Privacy
